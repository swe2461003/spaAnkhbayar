# CON354 LMS SPA

ХААИС-ын DLMS загварт тулгуурласан, Vanilla JavaScript ашигласан сургалтын удирдлагын SPA төсөл. React, Next.js, Vue ашиглаагүй. Номын router → pages → layouts → navbar → i18n → services → search → images → bilingual data → overview → calculation → materials → footer гэсэн дарааллыг LMS сэдэвт тохируулсан тайлбар нь **BOOK-GUIDE.md** файлд бий.

## Ажиллуулах

Node.js 20 буюу түүнээс дээш хувилбар хэрэгтэй. Төслийн хавтсанд терминал нээгээд:

```sh
npm ci
npm start
```

Дараа нь **http://127.0.0.1:4173** хаягийг нээнэ. Үүрэг болон демо нэрээ сонгоод орно. Нууц үг хэрэггүй. CSS, icon, зураг, PDF бэлэн орсон тул зөвхөн ажиллуулах бол `npm ci` хийхгүйгээр `node tools/serve.mjs` ажиллуулж болно. `index.html`-ийг file:// хаягаар шууд нээхгүй: ES modules, JSON fetch нь HTTP сервер шаарддаг.

```sh
npm run sass       # SCSS өөрчлөлтийг CSS рүү автоматаар хөрвүүлэх
npm run check      # JavaScript syntax болон relative import шалгах
npm test           # Тооцоолол, шүүлтүүр, escape, attendance тест
npm run test:e2e   # Тусгаарласан headless Chrome дахь браузерын тест
npm run build     # images.json, CSS, docs/ статик хувилбарыг бэлтгэх
```

`test:e2e` нь Google Chrome суусан Windows дээр шууд ажиллана. Өөр орчинд `CHROME_PATH` орчны хувьсагчаар Chrome executable зам өгнө, эсвэл `npx playwright install chromium` нэг удаа ажиллуулна. Тест нь өөрийн хоосон браузерын орчин, 4183 порт ашиглана; таны нээлттэй Chrome-ийн профайл болон бодит өгөгдөлд хүрэхгүй.

## Боломжууд

- Dashboard: 6 хичээл, хоёр мэргэжлийн шүүлтүүр, бодит жишээ өгөгдлөөс тооцсон статистик, долоо хоногийн ирц, дундаж дүн, чиглэлээс хайлт руу шилжих холбоос.
- Хичээл: код, Монгол/Англи нэр, багшаар хайх; мэргэжил, төрлөөр шүүх; эрэмбэлэх; дэлгэрэнгүй харах; зураг modal; CSV татах. Хэл солиход шүүлтүүр хадгалагдана.
- Ирц: хичээл/өдөр сонгох, сарын календарь, ирсэн/тасалсан/хоцорсон төлөв, хадгалалт. Статистикт хоцролтыг ирсэнд тооцно. Календарийн өнгө нь сонгосон хичээлийн тухайн өдрийн бүртгэлийн хамгийн анхаарах төлөвийг харуулна.
- Журнал: оюутны ID, анги, мэргэжил, оноо засах, нийт/үсгэн үнэлгээ, огноо/сэдэв/тэмдэглэл нэмэх. Оноог 20/30/20/30 хязгаарт шалгана.
- Хуваарь: таван өдрийн хүснэгт, шалгалтын огноо, даалгаврын хугацаа, сэдэвчилсэн төлөвлөгөө.
- Дүнгийн тооцоо: хичээл нэмэх/хасах, бүрэлдэхүүн тус бүрийн 0–100 хувийг жинлэх, кредитээр жинлэсэн GPA, тооцоогоо хадгалах.
- Материал: хичээлээр хайх, local PDF харах/татах. Бүх карт нэг жишээ удирдамжийг нээнэ; багшийн жинхэнэ лекцийн файлууд зохиогоогүй. Өөрийн PDF-үүдийг `src/pdf/`-д хийгээд `src/data/books.json`-д замыг солино.
- Мессеж: гурван демо харилцагч, түүх, HTML-ээс хамгаалсан текст, хадгалалт.
- Санал: ангилал, нэргүй сонголт, жагсаалт/шүүлтүүр, багш/админы төлөв өөрчлөх.
- Logs: жинхэнэ демо үйлдлээс бүртгэл үүсэх, хайх/шүүх, 8 мөрийн хуудаслалт, CSV. IP хаяг цуглуулахгүй.
- Архив: хичээл/ирц/журнал/шалгалтын 4 таб, улирал/мэргэжил/хайлт, CSV. Өмнөх улирлын өөрчлөгдөхгүй жишээ өгөгдөл.
- Монгол/Англи хэл, responsive sidebar, keyboard focus, Escape-аар modal хаах, loading/error/retry/empty төлөвүүд.

## Бүтэц

```text
src/
  index.html
  js/
    app.js, router.js, routes.js, config.js
    pages/        # Хуудас бүр тусдаа

    components/   # navbar, footer, cards, calendar, modal, reusable UI

    fn/           # format, filter, grade calculation

  data/           # Бүгд жишээ, бодит оюутны мэдээлэл биш
  scss/           # Sass эх файлууд, components/layouts partials
  css/            # Браузерт бэлэн хөрвүүлсэн CSS
  img/            # Төсөлд зориулан зурсан SVG assets
  pdf/            # Жишээ PDF
  tools/          # images.json болон bilingual migration хэрэгслүүд
  vendor/         # Local Font Awesome CSS, fonts, license
tools/            # Local server, build, syntax check, PDF generator
tests/            # Unit ба browser tests
docs/             # npm run build-ээр үүсэх статик хувилбар
```

## Өгөгдөл ба хязгаар

Энэ бол **браузерт ажиллах сургалтын демо**. Нэвтрэлт, эрхийн хязгаарлалт нь UI болон local service түвшний жишээ; серверийн баталгаажуулалт биш. Бодит сургуулийн системд хэрэглэхийн өмнө сервер, өгөгдлийн сан, хэрэглэгчийн баталгаажуулалт, серверийн эрхийн шалгалт шаардлагатай. Чат, санал нь бусдад илгээгдэхгүй. Нэргүй саналын текст/хэрэглэгчийг logs-д бичихгүй ч энэ нь бодит серверийн нууцлалын баталгаа биш.

Өгөгдөл `con354.v1.*`, хэл `con354.language` нэртэй localStorage түлхүүрт хадгалагдана. Өөр браузер, компьютер, эсвэл өөр порт руу автоматаар синк хийхгүй. Браузерын тухайн сайтын өгөгдлийг цэвэрлэвэл JSON жишээ өгөгдлөөс дахин эхэлнэ. Private mode/quota зэргээс хадгалалт хаагдвал хадгалалт амжилттай болсон гэж үзэхгүй.

Огноог Asia/Ulaanbaatar цагаар харуулна. Dashboard-ийн ирцийн график 2026.11.09–13-ны жишээ долоо хоног; өнөөдрийн бодит ирц гэж нэрлээгүй. 90/80/70/60 онооны A/B/C/D/F, 4/3/2/1/0 голч нь **төслийн жишээ дүрэм** болохоос сургуулийн баталгаажсан журам биш. Дүрмийг `gradeRequirements.json`-д сольж болно.

## Нийтлэхээс өмнө

`docs/` нь зөвхөн бэлдсэн файл. GitHub remote тохируулаагүй, push хийгээгүй, Pages идэвхжүүлээгүй. Classroom-д файл илгээгээгүй. Эдгээрийг хэрэглэгчийн тусдаа зөвшөөрлийн дараа хийнэ.
